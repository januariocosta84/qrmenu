{% icon "printer" %} {% translate "Set up the receipt printer and cash drawer (about 10 minutes)" %}

  1. {% translate "Install the printer on the cashier computer." %} {% translate "Connect it by USB (or Wi-Fi/Bluetooth), install the driver from the printer's CD or the maker's website, and set it as the default printer. Choose 80 mm paper (or 58 mm for small printers)." %}
  2. {% translate "Plug in the cash drawer." %} {% translate "The drawer cable (a phone-style plug) goes into the printer's port marked “DK” or “Drawer”." %}
  3. {% translate "Tell the printer driver to open the drawer." %} {% translate "On Windows: Settings → Printers → your receipt printer → Printing preferences (or Printer properties). Look for “Cash drawer” or “Peripherals” and choose “Open drawer #1 before printing”. The name varies by brand:" %}
    • Epson TM · {% translate "Printing preferences → Document settings / Printer settings → Cash drawer → “Open drawer #1 before printing”." %}
    • Xprinter, POS-80, Rongta · {% translate "Printer properties → Device settings → “Cash drawer” → open before printing." %}
    • Star TSP · {% translate "Printer properties → Device settings → Peripheral unit type “Cash drawer”, open at “Document top”." %}
  4. {% translate "Turn on the switch above and save." %} {% translate "From now on, every cash payment and every “Open drawer (no sale)” prints a small slip, and the driver opens the drawer." %}
  5. {% translate "Optional: print without the print window." %} {% translate "Make a Chrome shortcut for the dashboard: right-click the Chrome icon → Properties, and add --kiosk-printing at the end of “Target” (after the quotes). Open the dashboard with that shortcut, and receipts and slips print immediately on the default printer." %}
  6. {% translate "Test it" %} · {% translate "use “Print test slip” below. The slip should print and the drawer should open. If the drawer stays closed, check step 3 (some drawers need “drawer #2”)." %}

{% translate "Phones and tablets: print through the printer maker's app or print service. Whether the drawer opens depends on that app." %}
